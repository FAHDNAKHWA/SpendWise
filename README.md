### SpendWise — Track. Understand. Grow.

🌱 **SpendWise** is a sleek, modern personal expense tracker designed with a unique botanical aesthetic. Built entirely as a single-file, client-side web application, it helps you log everyday purchases, monitor category breakdowns through growing stems charts, and take full control of your finances.

---

### ✨ Features

* **⚡ Real-Time Ledger:** Easily add, edit, and delete transactions with instant state updates.
* **🌿 Visual Growth Chart:** Watch your spending habits visually take shape with a custom "growing stems" category breakdown.
* **🔍 Search & Filter:** Quickly narrow down entries by keywords, descriptions, or specific categories (Food, Travel, Shopping, Education, Other).
* **💾 Local Storage Persistence:** Your financial data stays safely stored right in your browser.
* **📱 Responsive & Fluid:** Features a clean, accessible interface optimized seamlessly for both desktop and mobile screens.

---

### 🚀 Getting Started

Since **SpendWise** is built entirely using vanilla HTML, CSS, and JavaScript, there are no complex build steps or server configurations required!

1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser.
3. Start logging your expenses and watch your savings grow!
